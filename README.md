## Grasshopper Template files in the repository

This repo includes a simple website that lists all `*.gh` files with their directory structure.

### One-time setup

1. In GitHub, open **Settings > Pages**.
2. Set **Source** to **GitHub Actions**.
3. Push to the default branch (or run the `Deploy Grasshopper Template files` workflow manually).

The site will be available at:

- `https://urbano-io.github.io/Urbano2-GH-Templates/`
